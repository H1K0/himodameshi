## Как запустить локально

Поскольку фронтенд находится внутри общей папки `web`, все команды нужно выполнять именно из неё.

### 1. Перейдите в папку фронтенда
Откройте терминал в корне репозитория и выполните:
```bash
cd web
```

### 2. Установите зависимости
(Это нужно сделать один раз, после клонирования репозитория)

```bash
npm install
```

### 3. Запустите сервер разработки
```bash
npm run dev
```
Откройте браузер и перейдите по адресу: http://localhost:5173

### Структура папки web
web/
├── src/
│   ├── lib/
│   │   └── store.svelte.ts   # Глобальное хранилище данных (профиль, команды)
│   ├── routes/               # Все страницы приложения
│   │   ├── +layout.svelte    # Общий каркас (Сайдбар, меню)
│   │   ├── +page.svelte      # Страница "Моя страница" (Профиль)
│   │   └── teams/            # Раздел команд
│   │       ├── +page.svelte  # Список команд и настройки
│   │       └── cables/       # Раздел кабелей
│   │           ├── +page.svelte                  # Список кабелей
│   │           └── [id]/                         # Конкретный кабель
│   │               ├── +page.svelte              # Детали кабеля + таблица измерений
│   │               └── measurements/[measureId]/ # Конкретное измерение
│   │                   └── +page.svelte          # Результаты тестов
│   ├── app.css               # Глобальные стили
│   └── app.html              # Основной HTML-каркас
├── static/                   # Статические файлы (логотип logo.png)
├── package.json              # Зависимости фронтенда
└── vite.config.ts            # Настройки Vite
