## Как запустить локально

Поскольку фронтенд находится внутри общей папки `web`, все команды нужно выполнять именно из неё.

### 1. Перейдите в папку фронтенда
Откройте терминал в корне репозитория и выполните:
```bash
cd web
```

### 2. Установите зависимости
(Это нужно сделать один раз, после клонирования репозитория)

```bash
npm install
```

### 3. Запустите сервер разработки
```bash
npm run dev
```
Откройте браузер и перейдите по адресу: http://localhost:5173

### Сборка и развёртывание

Веб — SPA на `@sveltejs/adapter-static` ([ADR-015](../docs/adr/015-hub-stack.md)). `npm run build` складывает статику в `build/`, в образе её раздаёт сервер Hub: существующий файл — как есть, любой другой путь вне `/api` — `index.html`, дальше маршрут разбирает роутер SvelteKit в браузере. Отдельного деплоя у веба нет: после слияния в `dev` он выезжает на dev вместе с Hub, на prod — с тегом `hub/vX.Y.Z` (подробнее — [deploy/README.md](../deploy/README.md)). В PR сборку проверяет `web-ci`.

Что из этого следует:

- Серверной части у SvelteKit нет (`ssr = false` в `src/routes/+layout.ts`): файлы `+page.server.ts`, `+server.ts` и form actions не работают. Данные берутся только из API Hub.
- После `git pull`, если изменился `package-lock.json`, выполните `npm install`.

### Структура папки web
web/
├── src/
│   ├── lib/
│   │   └── store.svelte.ts   # Глобальное хранилище данных (профиль, команды)
│   ├── routes/               # Все страницы приложения
│   │   ├── +layout.svelte    # Общий каркас (Сайдбар, меню)
│   │   ├── +page.svelte      # Страница "Моя страница" (Профиль)
│   │   └── teams/            # Раздел команд
│   │       ├── +page.svelte  # Список команд и настройки
│   │       └── cables/       # Раздел кабелей
│   │           ├── +page.svelte                  # Список кабелей
│   │           └── [id]/                         # Конкретный кабель
│   │               ├── +page.svelte              # Детали кабеля + таблица измерений
│   │               └── measurements/[measureId]/ # Конкретное измерение
│   │                   └── +page.svelte          # Результаты тестов
│   ├── app.css               # Глобальные стили
│   └── app.html              # Основной HTML-каркас
├── static/                   # Статические файлы (логотип logo.png)
├── package.json              # Зависимости фронтенда
└── vite.config.ts            # Настройки Vite
