# 紐試し · Himo

**ПАК «Химодамэси» (Himo)** — тестер аудиокабелей для музыкантов: прибор, мобильное приложение и веб-сервис.

Прибор проводит электрические измерения кабеля — целостность проводников, CMRR, АЧХ — и передаёт их в приложение по Bluetooth. Приложение выдаёт понятный вердикт: кабель исправен, требует внимания или подлежит замене; хранит историю проверок, паспорт кабеля и Health Score, объясняет результаты ИИ-комментариями. Веб-сервис **Himo Hub** — «GitHub для кабелей»: команда ведёт общий парк кабелей, а история тестов не теряется при смене телефона или ответственного.

Целевая аудитория — музыканты, студии, концертные площадки и прокатные компании.

## Состав и статус

| Компонент            | Что делает                                                                  | Состояние                                                         |
| -------------------- | --------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| Прибор               | Измеряет кабель, передаёт результаты в приложение по BLE                    | Реализация отложена ([ADR-013](docs/adr/013-device-postponed.md)) |
| Мобильное приложение | Тестирование, Health Score, паспорт, история, ИИ-комментарии, синхронизация | Работает на mock-данных прибора                                   |
| Himo Hub             | Команды, общая история кабелей, синхронизация, веб-интерфейс                | Требования и стек определены, кода пока нет                       |

Схема компонентов и их связей — [docs/spec/architecture.md](docs/spec/architecture.md).

## Локальный запуск

### Мобильное приложение

**Требования:** Flutter SDK 3.x, Android Studio или VS Code с плагином Flutter.

```bash
cd app
flutter pub get
flutter run
```

Приложение запускается с mock-данными — прибор не нужен.

### Himo Hub

Сервер, веб и PostgreSQL будут подниматься одной командой `docker compose up --build`, миграции применятся при первом запуске. Инструкция появится вместе с каркасом `hub/`.

### Прошивка (заморожено)

Реализация прибора отложена ([ADR-013](docs/adr/013-device-postponed.md)). Для справки: прошивка собирается в VS Code с расширением PlatformIO, ESP32-S3 подключается по USB-C.

```bash
cd firmware
pio run --target upload
```

## Развёртывание

Himo Hub разворачивается на домашнем сервере: Docker Compose, nginx с сертификатами Let's Encrypt, автоматический деплой через Gitea Actions.

| Окружение | Адрес                          | Обновляется                      |
| --------- | ------------------------------ | -------------------------------- |
| prod      | `https://himo.hakoniwa.ru`     | по тегу релиза `hub/vX.Y.Z`      |
| dev       | `https://dev.himo.hakoniwa.ru` | при каждом слиянии в ветку `dev` |

Адреса пока не настроены — появятся вместе с первым деплоем. Подробности — [ADR-017](docs/adr/017-deployment.md).
