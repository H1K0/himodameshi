# 紐試し · Himo

**Himo** — программно-аппаратный тестер аудиокабелей с мобильным приложением.

Устройство подключается к смартфону по Bluetooth, проводит серию электрических измерений и выдаёт понятный вердикт: кабель исправен, требует внимания или подлежит замене. В отличие от LED-тестеров — цифровые измерения, история проверок, паспорт кабеля и Health Score.

Целевая аудитория MVP — музыканты-любители: гитаристы, клавишники, домашние студийщики.  
Ценовой диапазон: €129–159.

## MVP-тесты

- **Целостность** — сопротивление каждого проводника, выявление обрыва и КЗ
- **CMRR** — коэффициент подавления синфазной помехи для балансных линий
- **АЧХ** — амплитудно-частотная характеристика передачи сигнала (10 Гц – 40 кГц)

## Быстрый старт

### Мобильное приложение

**Требования:** Flutter SDK 3.x, Dart 3.x, Android Studio или VS Code с плагином Flutter.

```bash
cd app
flutter pub get
flutter run
```

Приложение запускается с mock-данными — реальное устройство не требуется. Это позволяет разрабатывать и тестировать UI независимо от аппаратной части.

### Прошивка

**Требования:** VS Code с расширением PlatformIO, подключённый ESP32-S3 по USB-C.

```bash
cd firmware
# Открыть папку в VS Code с расширением PlatformIO
# Выбрать окружение: esp32-s3-devkitc
pio run --target upload
```
