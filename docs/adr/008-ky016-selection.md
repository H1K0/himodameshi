# ADR-008: Выбор модуля KY-016 для RGB-индикатора

## Контекст

В BOM зафиксирован RGB LED как визуальный индикатор Health Score. Необходимо определить конкретный модуль для прототипа: дискретный светодиод с резисторами или готовый модуль.

## Решение

Использовать модуль KY-016 (RGB LED с тремя токоограничивающими резисторами, общий катод). Модуль подключается напрямую к GPIO ESP32-S3 без внешней обвязки. Доступен на OZON и AliExpress (российские склады).

## Варианты, которые рассматривались

- **Дискретный RGB LED + резисторы** — стандартный подход для конечного изделия. Отклонён на этапе прототипа: требует точного подбора резисторов и пайки, замедляет итерации.
- **WS2812B (адресный)** — избыточен: управление через однопроводный протокол, нужна отдельная библиотека. Для одного индикатора нецелесообразен.
- **KY-016** — готовый модуль с резисторами, подключается к трём PWM-пинам ESP32-S3. Оптимален для прототипа; при переходе к PCB заменяется на дискретный компонент без изменений в прошивке.

## Последствия

KY-016 зафиксирован для прототипной сборки. Прошивка управляет тремя PWM-каналами (R/G/B). Для финального PCB компонент будет заменён на дискретный RGB LED с соответствующими резисторами — интерфейс прошивки при этом не меняется.
