# ADR-009: Замена ADS1115 на MCP3208 как единый АЦП для всех тестов MVP

## Контекст

В версии архитектуры 0.4 для аналоговых измерений был выбран ADS1115 — 16-битный дельта-сигма АЦП с интерфейсом I2C. На момент выбора предполагалось, что его характеристик хватит для всех трёх тестов MVP: целостности, CMRR и АЧХ.

При проработке теста АЧХ выяснилось, что максимальная частота дискретизации ADS1115 — 860 SPS — недостаточна для измерения сигналов до 40 кГц. По теореме Котельникова требуется не менее 80 кSPS, на практике — 100+ кSPS с запасом. Это означает, что для теста АЧХ в любом случае нужен второй, более быстрый АЦП.

Возникли два пути: оставить ADS1115 для целостности и CMRR, добавив быстрый АЦП только для АЧХ, либо подобрать единый АЦП, покрывающий все три теста.

## Решение

Полностью заменить ADS1115 на **MCP3208** — 12-битный SAR АЦП с интерфейсом SPI, частотой дискретизации 100 кSPS и 8 каналами (4 в дифференциальном режиме).

MCP3208 становится единственным АЦП в системе и обслуживает все три теста MVP.

## Варианты, которые рассматривались

- **ADS1115 + быстрый АЦП параллельно.** Сохраняет 16 бит и низкий шум ADS1115 для целостности и CMRR, но усложняет схему: два разных интерфейса (I2C + SPI), два драйвера в прошивке, две процедуры калибровки. Архитектурно избыточно для MVP.
- **MCP3201.** Один канал, нет дифференциального режима — не подходит для теста CMRR с выходом INA128P.
- **MCP3202.** Подходит функционально (2 канала, есть дифференциальный режим), но ограничивает развитие: для версии 2 с TDR и дополнительными измерительными точками потребуется внешний мультиплексор или замена АЦП.
- **Встроенный АЦП ESP32-S3 для АЧХ + ADS1115 для остального.** Не требует докупки компонентов, но встроенный АЦП ESP32 шумный и нелинейный — для абсолютных измерений АЧХ потребовалась бы калибровка по опорному измерению, а архитектура остаётся с двумя АЦП.
- **ADS7883, AD7980 и другие быстрые АЦП высокого класса.** Избыточны по характеристикам, дороже, хуже доступны на российском рынке.

## Последствия

**Положительные:**

- Один АЦП вместо двух — упрощается схема, прошивка, BOM и калибровка.
- AD9833 и MCP3208 работают на общей шине SPI с разными CS, что упрощает разводку и синхронизацию генерации с измерением.
- 8 каналов дают задел на версию 2 (TDR, дополнительные измерительные точки) без необходимости менять АЦП или добавлять внешний мультиплексор.
- Дифференциальный режим позволяет подключить выход INA128P напрямую, без схемы смещения уровня.
- Стоимость и доступность сопоставимы с ADS1115; общая стоимость BOM не растёт.

**Ограничения:**

- Разрядность снижается с 16 до 12 бит (разрешение ~0.8 мВ при опоре 3.3 В вместо ~50 мкВ). Для измерений в диапазонах MVP — единицы-десятки Ом сопротивления, десятки-сотни мВ амплитуды — этого запаса хватает.
- Уровень шума у SAR АЦП выше, чем у дельта-сигма ADS1115. В тесте АЧХ это всё равно неизбежно (для скорости 100 кSPS нужен SAR), а в тесте целостности и CMRR компенсируется усреднением и аналоговым усилением через INA128P.
- Отсутствие встроенного PGA компенсируется регулируемым усилением INA128P перед АЦП. С точки зрения шумов такое разделение даже корректнее.
