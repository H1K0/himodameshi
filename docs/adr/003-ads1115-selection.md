# ADR-004: Выбор ADS1115 вместо MCP3204

## Контекст
Для точных аналоговых измерений нужен внешний АЦП — встроенный в ESP32-S3 недостаточно точен для аудиоизмерений. Изначально в документации был указан MCP3204 (12-bit, SPI), однако при проверке доступности на российском рынке он оказался труднодоступен.

## Решение
Использовать ADS1115: 16-bit, интерфейс I2C, свободно доступен на OZON и AliExpress (российские склады).

## Варианты, которые рассматривались
- **MCP3204** — оригинальный выбор, 12-bit, SPI. Недоступен в РФ в нужные сроки.
- **ADS1115** — 16-bit, I2C. Более высокое разрешение является преимуществом для точности измерений. I2C вместо SPI не является проблемой: у ESP32-S3 достаточно периферии для обоих протоколов одновременно.

## Последствия
ADS1115 зафиксирован в BOM прототипа. Переход с SPI на I2C потребует соответствующей разводки на плате и использования I2C-библиотеки в прошивке вместо SPI. Более высокое разрешение (16 бит против 12) даёт запас по точности сверх заявленного требования 1%.
