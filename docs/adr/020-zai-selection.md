## Контекст

Изначально для формирования комментариев на естественном языке были выбраны правила с шаблонами [ADR-004](004-insight-generator.md). После уточнения требований от преподавателей было сделано решение вместо правил подключить LLM. Поэтому встал вопрос выбора подходящей LLM. 
Бюджет минимален, поэтому и LLM должна стоит минимум (в идеале бесплатная). 
Решение также должно быть доступно в РФ без дополнительных средств.

## Решение

Использовать GLM-4.7-Flash через OpenAI-совместимый API. Из изменения интерфейсов только API: выбор модели определяет endpoint (`https://api.z.ai/api/paas/v4/chat/completions`) и поле `model` (`glm-4.7-flash`) в запросе. Формат запроса — OpenAI-совместимый (`messages` с ролями `system` / `user`, ответ в `choices[0].message.content`). Нестандартных расширений протокола нет — при смене провайдера на другого OpenAI-совместимого меняются только endpoint и model.

## Рассмотренные варианты

- **OpenRouter.ai** — единый API-шлюз, дающий доступ к сотням AI-моделей от разных провайдеров через один ключ и совместимый с OpenAI интерфейс. Из плюсов можно отметить большое количество моделей, в том числе бесплатных. Не подошел, потому что недоступен в РФ.
- **DeepSeek API** — облачный интерфейс для подключения модели DeepSeek. Не подошел, потому что не подтвердилась информация о 5М бесплатных токенах.
- **Gigachat-Lightning** — компактная и быстрая MoE-модель (10B-A1.8B) из линейки GigaChat 3.0. Плюсы: хорошо работает с русским языком. Не подошёл, потому что оказался платным.
- **GLM-4.7-Flash (выбран)**.

## Обоснование

Критерии в порядке важности: плата за использование > качество генерации > скорость работы.

Выбранная модель является единственным бесплатным и доступным в РФ из рассмотренных вариантов.

## Последствия

**Плюсы:**

- Использование выбранной модели полностью бесплатное.

**Минусы и ограничения:**

- Сервис может быть временно недоступен.
- Сервис имеет ограниченное количество запросов в минуту. 
- Сервис может выполнять только один запрос одновременно.
