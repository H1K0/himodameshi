# ADR-002: Выбор INA128P вместо INA217

## Контекст
Для теста CMRR нужен инструментальный усилитель с высоким коэффициентом подавления синфазной помехи. Изначально в документации был указан INA217, однако при проверке доступности компонентов на российском рынке он оказался недоступен (Chipdip, OZON).

## Решение
Использовать INA128P: CMRR ≥ 100 дБ, корпус DIP-8, свободно доступен в Chipdip. Характеристики полностью покрывают требования MVP.

## Варианты, которые рассматривались
- **INA217** — оригинальный выбор, недоступен в РФ.
- **INA163** — есть в наличии, но избыточен по характеристикам и дороже.
- **INA128P** — доступен, характеристики подходят, корпус DIP-8 удобен для макетной платы на этапе прототипа.

## Последствия
INA128P зафиксирован в BOM и будет использоваться в схеме. При необходимости замены в будущем нужно проверить распиновку и пересмотреть схему усилителя. Выбор компонентов в целом по проекту ориентирован на доступность в РФ (OZON, Chipdip) — это общий принцип, а не исключение.
