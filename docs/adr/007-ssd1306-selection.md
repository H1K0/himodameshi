# ADR-007: Выбор контроллера SSD1306 для OLED-дисплея

## Контекст

В BOM зафиксирован OLED-дисплей 128×64 для локального отображения данных в автономном режиме. Необходимо выбрать конкретный модуль с учётом доступности, поддержки в экосистеме Arduino/ESP-IDF и наличия датчика.

## Решение

Использовать OLED-модуль 128×64 на контроллере SSD1306, интерфейс I2C. Модуль доступен на OZON и AliExpress (российские склады). Для прошивки используется библиотека Adafruit SSD1306 (совместима с ESP32-S3 + Arduino), для которой существует обширная документация и примеры.

## Варианты, которые рассматривались

- **SH1106** — аналогичный контроллер с тем же разрешением, совместим с большинством библиотек SSD1306, но менее распространён. Нет преимуществ перед SSD1306 для данного применения.
- **SSD1306 (SPI)** — вариант с SPI-интерфейсом. Отклонён: I2C достаточен для частоты обновления дисплея (~1 Гц в автономном режиме), а освобождение линий SPI оставляет шину для AD9833.

## Последствия

SSD1306 зафиксирован в BOM. Прошивка будет использовать библиотеку Adafruit SSD1306. ADS1115 заменён на MCP3208 (SPI) по [ADR-009](009-mcp3208-selection.md) — SSD1306 является единственным устройством на шине I2C. Конфликта адресов нет.
