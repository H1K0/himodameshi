# ADR-009: Маркетинговое название Himo вместо Himodameshi

## Контекст
Полное название проекта — Himodameshi (紐試し) — игра слов на основе японского понятия кимодамэси (肝試し, «испытание печени»): слово кимо («печень») заменено на созвучное химо («шнурок»), что даёт значение «испытание шнурка», то есть кабеля. Название обладает смысловой глубиной и отражает суть продукта, однако для российского рынка оно длинное, сложно произносится и плохо запоминается.

## Решение
Использовать двухуровневую систему названий:

- **Himo** — рыночное название, используется в приложении, маркетинге, коммуникациях с пользователем.
- **Himodameshi / 紐試し** — полное внутреннее название, используется в документации, репозитории и как историческое обоснование происхождения.

## Варианты, которые рассматривались
- **Оставить Himodameshi как основное** — сохраняет смысловую целостность, но создаёт барьер восприятия: длинно, непривычное сочетание звуков для русскоязычного рынка, сложно произнести вслух при рекомендации.
- **Придумать функциональное русское название** — устранило бы проблему с произношением, но потеряло бы оригинальность и характер продукта. «Кабельтест», «КабельПро» и подобные варианты не создают запоминаемого образа.
- **Himo как самостоятельное название** — короткое, произносится на любом языке, легко пишется, сохраняет связь с полным названием. Необычность на российском рынке работает скорее в плюс: выделяется среди утилитарных названий конкурентов.

## Последствия
Во всех пользовательских интерфейсах, маркетинговых материалах и внешних коммуникациях используется только Himo. Полное название Himodameshi остаётся в технической документации, репозитории и может раскрываться как «история названия» — это добавляет продукту характер и является разговорной точкой при продвижении. Название репозитория — `himodameshi/`, папка приложения — `app/` (Flutter package name уточняется отдельно).
