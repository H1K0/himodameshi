## Организация процесса и методология

| Термин                   | Определение                                                                                                                                                                                                              |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **MVP**                  | Minimum Viable Product. Минимально жизнеспособная версия продукта — набор функциональности, достаточный для первого показа пользователям или инвесторам                                                                  |
| **ФТТ**                  | Функционально-технические требования. Документ с описанием того, что продукт должен уметь. В проекте — [docs/spec/requirements.md](requirements.md)                                                                      |
| **ADR**                  | Architecture Decision Record. Короткий документ, фиксирующий, _почему_ было принято конкретное архитектурное решение. Формат описан в [GIT_CONVENTIONS.md](../../GIT_CONVENTIONS.md), файлы лежат в [docs/adr/](../adr/) |
| **BOM**                  | Bill of Materials. Спецификация компонентов — список всего железа, которое нужно закупить для одного экземпляра устройства                                                                                               |
| **WIP**                  | Work In Progress. Незавершённая работа, не готовая к релизу                                                                                                                                                              |
| **Критический путь**     | Последовательность задач, которые нельзя распараллелить. Задержка любой задачи на критическом пути сдвигает весь проект                                                                                                  |
| **Триггер**              | Заранее согласованное условие, при наступлении которого выполняется заранее описанное действие (например, сокращение объёма работ)                                                                                       |
| **Заморозка фич**        | Момент, после которого в кодовую базу не добавляются новые фичи — только исправление ошибок                                                                                                                              |
| **Регрессионный прогон** | Повторный запуск всех тестовых сценариев для проверки, что изменения не сломали ранее работавшую функциональность                                                                                                        |
| **Clean Architecture**   | Подход к организации кода, при котором бизнес-логика изолирована от деталей реализации (UI, БД, внешних API). В приложении отражена разделением на `data/`, `domain/`, `presentation/`                                   |

## Продукт и функциональность

| Термин                   | Определение                                                                                                                                                                                                                                                                                                                                                  |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Health Score**         | Итоговая оценка состояния кабеля по шкале 0–100. Вычисляется как `100 − Σ штрафов` по применимым тестам. Цвет: 80–100 — зелёный (норма), 40–79 — жёлтый (отклонения), 0–39 — красный (критический дефект). Формула — в [requirements.md](requirements.md), ФТ-2.3                                                                                            |
| **Паспорт кабеля**       | Структурированный отчёт с уникальным идентификатором, фото, цветной меткой, историей тестов, результатами и итоговой оценкой. Экспортируется в PDF через системный share sheet                                                                                                                                                                               |
| **InsightGenerator**     | Модуль приложения, генерирующий комментарии к результатам тестов на естественном языке. В MVP — реализация на правилах и шаблонах с подстановкой реальных значений и вариативными формулировками. Оформлен как интерфейс, чтобы в V2 можно было подключить облачный LLM-слой (Premium-фича) без переделки UI. См. [ADR-004](../adr/004-insight-generator.md) |
| **Цветная метка**        | Один из элементов идентификации кабеля. Выбор из палитры для визуального различения кабелей в списке                                                                                                                                                                                                                                                         |
| **Целостность**          | Тест на обрыв и короткое замыкание. Измеряется сопротивление каждого проводника кабеля. Пороги по ФТТ: ОК (<5 Ом), Предупреждение (5–50 Ом), Обрыв, КЗ. См. подробно в [continuity-requirements.md](continuity-requirements.md)                                                                                                                              |
| **CMRR**                 | Common-Mode Rejection Ratio. Коэффициент подавления синфазной помехи — способность балансного кабеля подавлять наводки, приходящие одновременно на оба сигнальных проводника. Пороги по ФТТ: Отлично (>60 дБ) / Удовл. (40–60) / Плохо (<40). См. подробно в [cmrr-requirements.md](cmrr-requirements.md)                                                    |
| **АЧХ**                  | Амплитудно-частотная характеристика передачи сигнала. Зависимость уровня прошедшего через кабель сигнала от частоты в диапазоне 10 Гц – 40 кГц. Третий тест MVP по ФТТ. См. подробно в [freq-response-requirements.md](freq-response-requirements.md)                                                                                                        |
| **Свип частот**          | Последовательная подача сигналов разных частот для построения АЧХ. В MVP — 30 точек по логарифмической шкале от 10 Гц до 40 кГц                                                                                                                                                                                                                              |
| **Экранирование**        | Тест на качество экрана кабеля. **Не входит в MVP** — отнесён к V2                                                                                                                                                                                                                                                                                           |
| **Рефлектометрия (TDR)** | Метод определения длины кабеля и положения дефектов по анализу отражённых импульсов. **Не входит в MVP** — отнесён к V2                                                                                                                                                                                                                                      |
| **Триболюминесценция**   | Микрофонный эффект — возникновение шума в сигнале при механическом воздействии на кабель. **Не входит в MVP** — отнесён к V2                                                                                                                                                                                                                                 |

## Типы разъёмов и кабелей

| Термин                              | Определение                                                                                                                                                                                                        |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Jack 6.3 мм**                     | Стандартный инструментальный аудиоразъём. Используется для гитар, клавишных, студийного оборудования                                                                                                               |
| **TS**                              | Tip-Sleeve. Несимметричный (моно) Jack с двумя контактами: сигнал + земля                                                                                                                                          |
| **TRS**                             | Tip-Ring-Sleeve. Симметричный Jack с тремя контактами: два сигнальных проводника + земля. Позволяет передавать балансный сигнал                                                                                    |
| **XLR**                             | Профессиональный трёхконтактный разъём для балансной передачи сигнала. Используется для микрофонов, студийной и сценической аппаратуры                                                                             |
| **Балансный (симметричный) кабель** | Кабель с двумя сигнальными проводниками, по которым передаётся один и тот же сигнал в противофазе. На приёмной стороне разностный усилитель вычитает сигналы, подавляя помехи, наведённые одинаково на оба провода |
| **Несимметричный кабель**           | Кабель с одним сигнальным проводником и экраном-землёй. Подвержен наводкам                                                                                                                                         |

## Аналоговая схемотехника

| Термин                             | Определение                                                                                                                                                                                                                                                                                                                                                                                           |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Делитель напряжения**            | Схема из двух резисторов последовательно между питанием и землёй. Напряжение в точке их соединения: `V_mid = V_supply × R2 / (R1 + R2)`. В тесте целостности R2 — кабель, R1 — опорный резистор, V_mid измеряется АЦП                                                                                                                                                                                 |
| **R_ref / R_cable / V_mid**        | Переменные формулы теста целостности: R_ref — опорный резистор известного сопротивления; R_cable — измеряемый проводник кабеля; V_mid — напряжение в точке их соединения. Формула: `R_cable = R_ref × V_mid / (V_supply − V_mid)`                                                                                                                                                                     |
| **Синфазный сигнал**               | Сигнал, одновременно присутствующий на обоих проводниках балансной линии с одинаковой амплитудой и фазой. Возникает от внешних наводок (сетевой фон 50 Гц, электромагнитные помехи). Подавляется дифференциальным усилителем на приёмной стороне                                                                                                                                                      |
| **Дифференциальный сигнал**        | Разность сигналов между двумя проводниками балансной линии. Несёт полезный аудиосигнал. INA128P выделяет именно его, подавляя синфазную составляющую                                                                                                                                                                                                                                                  |
| **Импеданс**                       | Полное сопротивление цепи для переменного тока. Включает активную (резисторы) и реактивную (конденсаторы, катушки) составляющие. В CMRR-тракте рассогласование входных импедансов INA128P напрямую снижает CMRR прибора                                                                                                                                                                               |
| **Звездообразная земля**           | Схема разводки заземления, при которой все узлы подключаются к единой точке (звезде), а не цепочкой. Исключает протекание токов через общую шину земли и снижает шум между блоками                                                                                                                                                                                                                    |
| **Петли по земле**                 | Замкнутые контуры в цепях заземления, по которым протекают паразитные токи и создают шум. Основная причина нестабильных измерений CMRR на макетке с длинными проводами                                                                                                                                                                                                                                |
| **Буферный ОУ**                    | Операционный усилитель в режиме повторителя (усиление = 1). Применяется для развязки импедансов: высокоомный источник подключается к высокоомному входу ОУ, низкоомный выход ОУ управляет нагрузкой без потерь                                                                                                                                                                                        |
| **Пиковый детектор**               | Схема или алгоритм, фиксирующий максимальное значение (амплитуду) сигнала за период. В тесте АЧХ: на каждой частоте свипа МЦП3208 делает серию измерений, прошивка берёт максимум                                                                                                                                                                                                                     |
| **DDS**                            | Direct Digital Synthesis. Метод синтеза синусоидального сигнала: числовой генератор вычисляет мгновенные значения, ЦАП преобразует их в напряжение. Позволяет программно задавать точную частоту. Реализован в AD9833                                                                                                                                                                                 |
| **SAR АЦП**                        | Successive Approximation Register. Метод аналого-цифрового преобразования: последовательное приближение к значению входного сигнала методом двоичного поиска за N тактов (N — разрядность). MCP3208 — 12-битный SAR АЦП, одно преобразование за 12 тактов SPI                                                                                                                                         |
| **Нормировка АЧХ**                 | Приведение измеренных амплитуд к относительным единицам — отклонению в дБ от опорной частоты (1 кГц). Устраняет влияние абсолютного уровня сигнала и позволяет сравнивать кабели независимо от усиления тракта                                                                                                                                                                                        |
| **Антенный эффект**                | Нежелательный приём электромагнитного излучения незащищёнными проводами на макетке. На частоте 50 Гц длинные провода работают как антенны сетевого фона и вносят шум в измерения CMRR                                                                                                                                                                                                                 |
| **Потолок прибора (CMRR_ceiling)** | Максимальный CMRR, который способен измерить прибор — определяется качеством собственного измерительного тракта, а не кабеля. Измеряется калибровкой на «идеальном кабеле» (перемычка). Должен быть ≥ 65 дБ для осмысленных результатов                                                                                                                                                               |
| **Прямая наводка (crosstalk)**     | Прямое прохождение сигнала от выходного тракта (AD9833 → разъёмы) к входному (INA128P, MCP3208) по воздуху или через субстрат макетки — минуя кабель. Симметричная наводка безопасна (INA128P её подавляет), асимметричная ограничивает потолок CMRR. На 1 кГц при аккуратном монтаже — ≤ −85 дБ. Проверяется тестом CMRR без подключённого кабеля (см. [cmrr-requirements.md](cmrr-requirements.md)) |

| **DevKit**                      | Отладочная плата с микроконтроллером, готовая к прошивке по USB. Используется на этапе прототипирования до разводки собственной платы                                                                                       |

| **MCP3208**                     | 12-битный SAR АЦП, интерфейс SPI, 100 кSPS, 8 каналов (4 дифференциальных). Единый АЦП для всех трёх тестов MVP. Работает на общей SPI-шине с AD9833 через отдельный CS-пин. См. [ADR-009](../adr/009-mcp3208-selection.md) |
| **INA128P**                     | Инструментальный усилитель с высоким CMRR (≥100 дБ). Усиливает разность между двумя входами, подавляя синфазную составляющую. Используется для измерения CMRR кабелей. См. [ADR-002](../adr/002-ina128p-selection.md)       |
| **CD74HC4067**                  | 16-канальный аналоговый мультиплексор. Позволяет одним АЦП последовательно опрашивать много сигнальных линий, коммутируя их логическими уровнями                                                                            |
| **SSD1306**                     | Контроллер OLED-дисплея 128×64. Используется для локального отображения прогресса и результатов в автономном режиме устройства. См. [ADR-007](../adr/007-ssd1306-selection.md)                                              |
| **KY-016**                      | Готовый модуль RGB-светодиода с резисторами. Используется как быстрый визуальный индикатор Health Score. См. [ADR-008](../adr/008-ky016-selection.md)                                                                       |
| **TP4056**                      | Контроллер заряда литий-ионной батареи через USB. Обеспечивает безопасный заряд ячейки 18650                                                                                                                                |
| **18650**                       | Стандартный типоразмер литий-ионной аккумуляторной ячейки (диаметр 18 мм, длина 65 мм)                                                                                                                                      |
| **ОУ (операционный усилитель)** | Универсальный аналоговый усилитель. В контексте CMRR используется как буфер для снижения выходного импеданса источника                                                                                                      |
| **Breadboard (макетная плата)** | Беспаечная монтажная плата для быстрой сборки прототипа. Строки контактов соединены внутри, компоненты вставляются без пайки. Используется при приёмке компонентов и первичной проверке схемы                               |

## Интерфейсы и протоколы

| Термин                   | Определение                                                                                                                                                                                                                                                           |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **BLE**                  | Bluetooth Low Energy. Малопотребляющая версия Bluetooth. Основной канал связи устройства с приложением                                                                                                                                                                |
| **GATT**                 | Generic Attribute Profile. Архитектура профилей BLE, определяющая сервисы и характеристики, через которые обмениваются данными устройство и клиент                                                                                                                    |
| **GATT-сервер**          | Сторона BLE-соединения, предоставляющая данные. В проекте это прошивка на ESP32                                                                                                                                                                                       |
| **Сервис (BLE)**         | Логическая группировка характеристик в GATT. Идентифицируется UUID                                                                                                                                                                                                    |
| **Характеристика (BLE)** | Единица обмена данными в GATT. В проекте две: CMD (для команд от приложения к устройству) и DATA (для результатов измерений от устройства к приложению, через Notify)                                                                                                 |
| **Notify**               | Механизм BLE, при котором устройство само отправляет обновления клиенту, без запроса. Используется для передачи прогресса и результатов тестов                                                                                                                        |
| **UUID**                 | Universally Unique Identifier. 128-битный идентификатор сервисов и характеристик BLE                                                                                                                                                                                  |
| **MTU**                  | Maximum Transmission Unit. Максимальный размер пакета BLE. Стандартное значение 23 байта, расширенное — до 247. Важно для передачи JSON-пакетов с результатами, особенно `result:freq_response` (массив 30 значений)                                                  |
| **I2C**                  | Двухпроводный синхронный интерфейс для связи микроконтроллера с периферией. Используется для SSD1306 (OLED-дисплей). MCP3208 и AD9833 работают на SPI                                                                                                                 |
| **SPI**                  | Четырёхпроводный синхронный интерфейс для высокоскоростной связи с периферией. Сигналы: MOSI (данные к устройству), MISO (данные от устройства), SCK (тактирование), CS/SS (выбор чипа — активирует конкретное устройство на шине). Используется для AD9833 и MCP3208 |
| **CS (Chip Select)**     | Сигнал выбора чипа на SPI-шине. При переводе в низкий уровень конкретное устройство начинает слушать шину. Несколько устройств (AD9833, MCP3208) могут делить одну SPI-шину через отдельные CS-пины на ESP32                                                          |
| **UART / Serial**        | Последовательный интерфейс для отладочного вывода от ESP32 на компьютер через USB                                                                                                                                                                                     |
| **PWM**                  | Pulse-Width Modulation. Широтно-импульсная модуляция. Используется для управления яркостью KY-016                                                                                                                                                                     |
| **GPIO**                 | General-Purpose Input/Output. Программируемые цифровые пины микроконтроллера                                                                                                                                                                                          |
| **NVS**                  | Non-Volatile Storage. Энергонезависимая память ESP32, где хранятся калибровочные значения и настройки, сохраняющиеся после выключения                                                                                                                                 |
| **USB-C**                | Современный тип USB-разъёма. В устройстве используется для зарядки аккумулятора и отладки прошивки                                                                                                                                                                    |

## Единицы измерения

| Единица             | Что это                                                                                                                                                                 |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Ом (Ω), кОм**     | Единицы сопротивления (1 кОм = 1000 Ом). В тесте целостности: исправный проводник <5 Ом, обрыв — очень большое значение (в прошивке = 99999.0, порог >10 кОм), КЗ ~0 Ом |
| **В (вольт)**       | Единица электрического напряжения. В схеме: логика ESP32 — 3.3 В, USB-питание — 5 В, VREF для MCP3208 — 3.3 В                                                           |
| **мА (миллиампер)** | Единица тока (1/1000 ампера). Актуальна при расчёте энергопотребления схемы и ресурса батареи 18650                                                                     |
| **дБ**              | Децибел. Логарифмическая единица отношения двух величин: `20 × log10(V1/V2)` для напряжений. Используется для CMRR и отклонений АЧХ относительно опорного уровня        |
| **Гц, кГц**         | Герц, килогерц. Единицы частоты (1 кГц = 1000 Гц). Тестовый диапазон АЧХ — 10 Гц – 40 кГц; опорная частота CMRR — 1 кГц                                                 |
