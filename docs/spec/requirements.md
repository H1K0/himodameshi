## 1. Аппаратная часть

### ФТ-1.1 Подключение кабелей

Устройство должно иметь разъёмы для подключения тестируемых кабелей:

- Jack 6.3 мм — TS (моно, несимметричный) и TRS (симметричный)
- XLR 3-pin — male и female на обоих концах устройства

### ФТ-1.2 Генерация тестовых сигналов

- Синусоидальный сигнал 10 Гц – 40 кГц через DDS-генератор AD9833 — для теста АЧХ и CMRR
- Синфазный сигнал для теста балансной линии (CMRR)

Исключено из MVP: импульсы для рефлектометрии (TDR), вибромотор для триболюминесценции. Отложено на версию 2.

### ФТ-1.3 Регистрация сигналов

- Измерение сопротивления каждого проводника
- Измерение разностного напряжения через инструментальный усилитель INA128P
- Измерение уровня принятого сигнала через АЦП MCP3208 (12 бит, SPI, 100 кSPS) для всех трёх тестов

### ФТ-1.4 Питание

- Основное питание — Li-Ion аккумулятор 18650, контроллер заряда TP4056
- USB-C — зарядка аккумулятора и канал отладки прошивки
- Автономность — не менее 100 сессий тестирования на одном заряде

### ФТ-1.5 Интерфейсы

- Bluetooth Low Energy (BLE) — основной канал связи с мобильным приложением
- USB-C — зарядка и отладка (не является основным каналом передачи данных)
- OLED 128×64 — локальный дисплей для отображения статуса и результатов без телефона

## 2. Программная часть — мобильное приложение

### ФТ-2.1 Управление тестированием

- Выбор типа кабеля перед тестом: Jack TS, Jack TRS, XLR симметричный
- Запуск любого из трёх тестов по отдельности
- Запуск полного цикла: все три теста последовательно с итоговым отчётом

### ФТ-2.2 Измерения и анализ

| Тест        | Что измеряется                                                      | Пороги                                                |
| ----------- | ------------------------------------------------------------------- | ----------------------------------------------------- |
| Целостность | Сопротивление каждого проводника                                    | ОК (<5 Ом) / Предупреждение (5–50 Ом) / Обрыв / КЗ    |
| CMRR        | Коэффициент подавления синфазной помехи, дБ                         | Отлично (>60 дБ) / Удовл. (40–60 дБ) / Плохо (<40 дБ) |
| АЧХ         | Амплитудно-частотная характеристика передачи сигнала 10 Гц – 40 кГц | Отлично / Удовл. / Плохо                              |

Детальные требования к схеме и калибровке CMRR — **[cmrr-requirements.md](cmrr-requirements.md)**.
Детальные требования к схеме, алгоритму и калибровке теста целостности — **[continuity-requirements.md](continuity-requirements.md)**.
Детальные требования к схеме, пиковому детектору и калибровке теста АЧХ — **[freq-response-requirements.md](freq-response-requirements.md)**.

К каждому результату приложение формирует комментарий на естественном языке через `InsightGenerator` — правила и шаблоны с подстановкой реальных значений (см. [ADR-004](../adr/004-insight-generator.md)).

### ФТ-2.3 Отчётность и база данных

- **Health Score** — итоговая цветовая оценка кабеля по результатам всех тестов: зелёный / жёлтый / красный
- **Паспорт кабеля** — структурированный отчёт: идентификатор, дата, фото, результаты всех тестов, итоговая оценка
- **Экспорт** — PDF через системный share sheet (мессенджер, почта, AirDrop); QR-код генерируется как часть PDF для передачи паспорта при продаже или передаче кабеля
- **База кабелей** — локальная база с полной историей проверок для каждого кабеля

### ФТ-2.4 Идентификация кабелей

- Имя — свободный текст, задаётся при первом тесте
- Цветная метка — выбор из палитры для визуальной идентификации в списке
- Фото — снимок разъёма или бирки прямо в приложении

### ФТ-2.5 Интерфейс приложения

- **Dashboard** — список кабелей с Health Score, статус BLE-соединения с устройством
- **Тестирование** — выбор типа кабеля, пошаговый запуск, прогресс, результаты в реальном времени
- **Паспорт кабеля** — история тестов, динамика параметров, кнопка «Поделиться»
- **Коллекция** — фильтрация по статусу, поиск по имени и цвету
- **Настройки** — управление устройством, профиль пользователя

## 3. Нефункциональные требования

| Требование                        | Значение                               |
| --------------------------------- | -------------------------------------- |
| Погрешность амплитудных измерений | Не более 1%                            |
| Время полного цикла тестирования  | Не более 30 секунд                     |
| Питание устройства                | Li-Ion 18650, зарядка по USB-C 5 В     |
| Автономность                      | Не менее 100 сессий на одном заряде    |
| Платформы приложения              | iOS и Android (Flutter)                |
| Хранение данных                   | Локально на устройстве пользователя    |
| Облачная синхронизация            | Опционально, Premium-уровень, версия 2 |
