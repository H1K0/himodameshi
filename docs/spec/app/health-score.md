# Алгоритм Health Score · Himo

Версия 1.0 · Октябрь 2026

Требования к приложению → [requirements.md](requirements.md) (APP-3) · Обоснование → [ADR-011](../../adr/011-health-score-algorithm.md)

---

Health Score (0–100) — взвешенная сумма суб-скоров по **завершённым** тестам; каждый суб-скор опирается на **численные значения**, а не только на статусы. Статусы (`ok`, `excellent` и т. д.) остаются в таблицах результатов — для отображения в UI; Health Score — синтетический показатель для быстрой общей оценки.

## Применимость тестов по типу кабеля

| Тип кабеля | Целостность ($S_c$) | CMRR ($S_m$) | АЧХ ($S_f$) |
| ---------- | :-----------------: | :----------: | :---------: |
| `xlr`      |          ✓          |      ✓       |      ✓      |
| `jack_trs` |          ✓          |      ✓       |      ✓      |
| `jack_ts`  |          ✓          |      —       |      ✓      |

Тест CMRR недоступен для `jack_ts` (небалансный кабель) — его вес всегда исключён.

## Катастрофические условия

Если тест целостности завершён и у **любого** проводника статус `open` или `short` → $\text{health\_score} = 0$ без дальнейших вычислений (независимо от того, какие ещё тесты запущены). Если тест целостности не запускался — катастрофическое условие не проверяется.

## Суб-скор целостности $S_c$ (0–100)

Для каждого проводника $i$ с измеренным сопротивлением $r_i$ (Ω):

$$s_i = \begin{cases} 100 - 4\,r_i & r_i < 5\,\Omega \quad\text{(зона ok)} \\ \max\!\left(0,\; 80 - \dfrac{8}{9}(r_i - 5)\right) & r_i \geq 5\,\Omega \quad\text{(зона warning и выше)} \end{cases}$$

$$S_c = \frac{1}{n}\sum_{i=1}^{n} s_i$$

Граничные точки: $r = 0\,\Omega \Rightarrow s = 100$; $r = 5\,\Omega \Rightarrow s = 80$; $r = 50\,\Omega \Rightarrow s = 40$; $r \geq 95\,\Omega \Rightarrow s = 0$.  
Пороги из [device/continuity.md](../device/continuity.md): ok $< 5\,\Omega$, warning $5\text{–}50\,\Omega$.

## Суб-скор CMRR $S_m$ (0–100) — для XLR и Jack TRS

Применяется к балансным кабелям (`xlr`, `jack_trs`). Jack TS — небалансный, CMRR не измеряется.

$$S_m = \begin{cases} 0 & d < 20 \\ 2\,(d - 20) & 20 \leq d < 60 \\ \min\!\left(100,\; 80 + (d - 60)\right) & d \geq 60 \end{cases}$$

где $d$ — измеренное значение CMRR в дБ.

| $d$ (дБ)  | $S_m$ | Статус по ФТТ          |
| --------- | ----- | ---------------------- |
| $< 20$    | 0     | fail                   |
| $40$      | 40    | граница fail / ok      |
| $60$      | 80    | граница ok / excellent |
| $\geq 80$ | 100   | excellent              |

Пороги из [device/cmrr.md](../device/cmrr.md): fail $< 40\,\text{дБ}$, ok $40\text{–}60\,\text{дБ}$, excellent $> 60\,\text{дБ}$.

## Суб-скор АЧХ $S_f$ (0–100)

Если хотя бы одна точка содержит сентинел $-99.0$ (пропадание сигнала) → $S_f = 0$.

Значения $v_i$ — отклонение в дБ от опорного уровня 1 кГц; $v_{16} \equiv 0.0$ по определению ([BLE-протокол §4](../device/ble-protocol.md)).

**Зоны частот.** Из 30 точек (10 Гц – 40 кГц) формула использует две зоны с разной логикой:

- **20 Гц – 20 кГц** — основной аудиодиапазон; пороги ФТТ (±1 / ±3 дБ) заданы именно здесь.
- **20 кГц – 40 кГц** — сверхзвуковая зона; небольшой завал (≤ 3 дБ) естествен для кабелей длиной > 5 м, но значительный (> 3 дБ) указывает на раннюю ёмкостную деградацию.
- **10 Гц – 20 Гц** — точки измеряются и передаются в приложение для отображения полного графика и ИИ-комментариев, но **не** участвуют в расчёте score: пороги ФТТ на этот диапазон не распространяются.

**Основной скор (аудиодиапазон):**

$$\text{peak} = \max_i |v_i|, \qquad \sigma = \sqrt{\frac{1}{n}\sum_{i=1}^{n} v_i^2} \qquad \text{для точек } 20\,\text{Гц} \leq f \leq 20\,\text{кГц}$$

$$S_{f,\text{audio}} = \max\!\left(0,\; 100 - 14 \cdot \text{peak} - 6 \cdot \sigma\right)$$

$\text{peak}$ наказывает за локальный выброс, $\sigma$ — за систематический завал. При равномерном отклонении ($\sigma = \text{peak}$) формула даёт точные граничные значения.

**ВЧ-штраф (сверхзвуковая зона):**

$$\text{peak}_{hf} = \max_i |v_i| \qquad \text{для точек } 20\,\text{кГц} < f \leq 40\,\text{кГц}$$

$$\text{penalty}_{hf} = \max\!\left(0,\; (\text{peak}_{hf} - 3) \times 4\right)$$

**Итоговый суб-скор:**

$$S_f = \max\!\left(0,\; S_{f,\text{audio}} - \text{penalty}_{hf}\right)$$

| Профиль АЧХ                                | peak  | $\sigma$ | $\text{peak}_{hf}$ | $S_f$ | Статус по ФТТ |
| ------------------------------------------ | ----- | -------- | ------------------ | ----- | ------------- |
| Идеальная                                  | 0 дБ  | 0 дБ     | 0 дБ               | 100   | —             |
| Excellent-граница (равномерн.)             | ±1 дБ | 1 дБ     | 0 дБ               | 80    | excellent     |
| Ok-граница (равномерн.)                    | ±3 дБ | 3 дБ     | 0 дБ               | 40    | ok            |
| Один ВЧ-выброс ±6 дБ (норм. аудио)         | 0 дБ  | 0 дБ     | 6 дБ               | 88    | excellent     |
| Сильная ВЧ-деградация ±10 дБ (норм. аудио) | 0 дБ  | 0 дБ     | 10 дБ              | 72    | ok            |
| Fail (равномерн.)                          | ±5 дБ | 5 дБ     | 0 дБ               | 0     | fail          |

Пороги из [device/freq-response.md](../device/freq-response.md): excellent $\leq \pm1\,\text{дБ}$, ok $\leq \pm3\,\text{дБ}$ в диапазоне 20 Гц – 20 кГц.

## Базовые веса и итоговая формула

| Тип кабеля | $w_c$ | $w_m$ | $w_f$ | $\sum$ | Тип тракта  |
| ---------- | ----- | ----- | ----- | ------ | ----------- |
| `xlr`      | 0.35  | 0.35  | 0.30  | 1.00   | балансный   |
| `jack_trs` | 0.35  | 0.35  | 0.30  | 1.00   | балансный   |
| `jack_ts`  | 0.60  | —     | 0.40  | 1.00   | небалансный |

Для `jack_ts` CMRR не измеряется; $w_c + w_f = 1.0$ уже без него. Целостность получает больший вес, так как для небалансного кабеля именно она определяет пригодность к работе.

При всех запущенных тестах:

$$\text{health\_score} = \operatorname{round}(w_c \cdot S_c + w_m \cdot S_m + w_f \cdot S_f)$$

## Частичные тесты

Пользователь может запустить только часть применимых тестов. Алгоритм адаптируется автоматически:

- Если ни один тест не завершён → `health_score = NULL`.
- Если завершён хотя бы один тест — Health Score рассчитывается по завершённым тестам с **перераспределением базовых весов**:

$$w'_x = \frac{w_x}{\displaystyle\sum_{t \in T_{\text{run}}} w_t}, \qquad \text{health\_score} = \operatorname{round}\!\left(\sum_{t \in T_{\text{run}}} w'_t \cdot S_t\right)$$

где $T_{\text{run}}$ — множество завершённых тестов, $w_x$ — базовые веса из таблицы выше.

При $T_{\text{run}} = T_{\text{applicable}}$ нормировка тривиальна ($\sum w_t = 1{,}0$) и формула совпадает с полной.

**Примеры перераспределения весов (XLR):**

| Запущены тесты     | $w'_c$ | $w'_m$ | $w'_f$ |
| ------------------ | ------ | ------ | ------ |
| Все три            | 0.35   | 0.35   | 0.30   |
| Целостность + CMRR | 0.50   | 0.50   | —      |
| Целостность + АЧХ  | 0.54   | —      | 0.46   |
| Только целостность | 1.00   | —      | —      |

Частичный score отображается в UI с явной пометкой «неполный» и перечнем незавершённых тестов.
