## 1. Функциональные требования

### DVC-1 Подключение кабелей

Устройство должно иметь разъёмы для подключения тестируемых кабелей:

- Jack 6.3 мм — TS (моно, несимметричный) и TRS (симметричный)
- XLR 3-pin — male и female на обоих концах устройства

### DVC-2 Генерация тестовых сигналов

- Синусоидальный сигнал 10 Гц – 40 кГц через DDS-генератор AD9833 — для теста АЧХ и CMRR
- Синфазный сигнал для теста балансной линии (CMRR)

Исключено из MVP: импульсы для рефлектометрии (TDR), вибромотор для триболюминесценции. Отложено на версию 2.

### DVC-3 Регистрация сигналов

- Измерение сопротивления каждого проводника
- Измерение разностного напряжения через инструментальный усилитель INA128P
- Измерение уровня принятого сигнала через АЦП MCP3208 (12 бит, SPI, 100 кSPS) для всех трёх тестов

### DVC-4 Питание

- Основное питание — Li-Ion аккумулятор 18650, контроллер заряда TP4056
- USB-C — зарядка аккумулятора и канал отладки прошивки
- Автономность — не менее 100 сессий тестирования на одном заряде

### DVC-5 Интерфейсы

- Bluetooth Low Energy (BLE) — основной канал связи с мобильным приложением
- USB-C — зарядка и отладка (не является основным каналом передачи данных)
- OLED 128×64 — локальный дисплей для отображения статуса и результатов без телефона

## 2. Нефункциональные требования

| Требование                        | Значение                            |
| --------------------------------- | ----------------------------------- |
| Погрешность амплитудных измерений | Не более 1%                         |
| Время полного цикла тестирования  | Не более 30 секунд                  |
| Питание устройства                | Li-Ion 18650, зарядка по USB-C 5 В  |
| Автономность                      | Не менее 100 сессий на одном заряде |
